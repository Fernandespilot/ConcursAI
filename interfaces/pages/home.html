Sobre o Projeto

ConcursAI

Sistema desenvolvido como Trabalho de Conclusão de Curso com foco na aplicação de Inteligência Artificial para auxiliar candidatos em concursos públicos brasileiros.

Utiliza técnicas avançadas de RAG (Retrieval-Augmented Generation) combinando busca semântica vetorial com modelos de linguagem de última geração.

  • Busca semântica com ChromaDB e SentenceTransformers
  • Integração com Groq API (Llama 3.3 70B)
  • Coleta automática de editais das principais bancas
  • Análise inteligente de PDFs com extração de informações
  • Dashboard com monitoramento em tempo real
