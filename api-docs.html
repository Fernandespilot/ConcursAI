📋 Exemplos de Uso

🔍 Busca Simples de Concursos
# Python import requests response = requests.get('http://localhost:8000/api-brasil/concursos') concursos = response.json() print(f"Total de concursos: {len(concursos)}")
// JavaScript fetch('/api-brasil/concursos') .then(response => response.json()) .then(data => console.log('Concursos:', data));
